# CHECKLIST (デイリーチェックリスト)

航空のチェックリスト思想とSpaceXのデザイン哲学を踏襲した、個人の日常・業務向けAndroidチェックリストアプリ。
毎日使う前提で、操作を最小限に抑え、完全オフラインで完結します。

## 特徴

- **SpaceX Design Philosophy**
  - 完全な純黒背景（`#000000`）
  - ハイコントラストなモノトーン（アクセントカラー非使用）
  - 航空・宇宙計器をモチーフにした幾何学的タイポグラフィと線画アイコン
  - 枠線中心のボタンデザインと広めの余白
- **4フェーズ運用（朝・午前・午後・夜）**
  - 1日を4つのフェーズに分割し、コックピットUIでスムーズに切り替え
  - ホーム画面で全フェーズの状況を俯瞰（DAILY TIMELINE）
- **仕事用・単発タスクの常時設定**
  - 画面下部のクイック入力バーからダイアログ不要で即時追加
  - タスクごとの常時設定・編集（TASK CONFIG: 必須/普通の切り替え、タイトル編集）
  - 完了した単発タスクを1タップで一括整理（`CLEAR DONE`）
- **フェーズ完了時の振り返り**
  - フェーズ完了時に「問題なかった？」をYes/Noで確認
  - Noの場合のみ、次への改善メモを任意で記録
- **オフライン完結 & ローカル保存**
  - すべてのデータは端末内に安全にJSON永続化

## 開発環境

- **言語**: Kotlin
- **UIフレームワーク**: Jetpack Compose (Material 3)
- **ビルドツール**: Android Gradle Plugin 9.0.1 / Gradle 9.0
- **ターゲット**: Android 16 (API 36) / 最小 API 26 (Android 8.0)
